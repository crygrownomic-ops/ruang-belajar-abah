# 🌟 Ruang Belajar Abah - Web Aplikasi SD Modular

Aplikasi web pembelajaran interaktif berbasis **Kurikulum Merdeka** untuk anak Sekolah Dasar (Fase A, B, C) dengan fitur integrasi **Google Gemini AI**, **Generator Soal Otomatis**, **Pencatatan Rapor Siswa Printable**, dan **Efek Suara Web Audio API**.

## 🛠️ Cara Menjalankan Proyek di VS Code
1. Clone / Download repository ini.
2. Buka folder `ruang-belajar-abah` di VS Code.
3. Gunakan extension **Live Server** di VS Code untuk membuka `index.html`, atau buka file `index.html` langsung di browser web.
